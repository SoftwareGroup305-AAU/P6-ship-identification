### Ship Identification Software for Drones

In protected environmental zones, some ships intentionally turn off their AIS (**Automatic Identification System**) to avoid detection, which poses a serious regulatory and environmental risk. AIS is a crucial system for tracking vessels, and its deactivation can indicate illegal activities such as unauthorized fishing or other environmental violations.

To address this issue, we aim to develop a **drone-based ship identification system** that can
- **Identify ships using AI-based recognition**, even if AIS is off  
- **Log their position** based on image data and GPS  
- **Report findings** to authorities for further investigation

Python versions:
- Drone interface: 3.12.6
- CNN: 3.11.2
